# CareerSync
### Personalized Career Opportunity Platform — UI/UX Concept

CareerSync is a UI/UX concept designed to bring different career opportunities into one personalized platform for students.
Instead of searching across multiple platforms, students can explore opportunities based on their skills, interests, academic year, and career goals.

🎨 Design
Designed using: Figma

📱 Designed Screens

- Splash Screen
- Onboarding
- Login Page
- Home Dashboard
- Explore Opportunities
- Opportunity Details
- Login page
- AI assistant
- Profile Page

✨ Key Features

- Personalized career dashboard
- Career goal tracking
- Skill-based recommendations
- Opportunity exploration
- Opportunity matching
- Career roadmap

🎯 Project Goal

To create a simple and personalized career platform that helps students discover relevant opportunities in one place.
